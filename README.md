# tiritara-privacy

tiritara.dev（tiritara）が公開するアプリのプライバシーポリシー。日本語・英語の静的HTMLを、GitHub Pagesで公開しています。

## 公開URL

- Android: https://kagen.github.io/tiritara-privacy/
- iOS・iPadOS共通: https://kagen.github.io/tiritara-privacy/ios.html
- iOS英語セクション: https://kagen.github.io/tiritara-privacy/ios.html#en

Androidの既存URLと本文は維持し、上部にiOSページへのリンクだけを追加しています。旧URL `kagen.github.io/kattalyst-privacy/` は既存アプリが掲載しているため、転送ページとして残してあります。

Androidページの `?app=アプリ名` は表示名だけを変更します。情報の取扱いを変更する機能ではありません。iOSページはアプリ名の差し替えに依存せず、共通方針とアプリ別の取扱情報を静的に掲載します。JavaScriptなしで全文を読めます。

## iOSアプリを追加するとき

同じ共通URLを複数のアプリで使用できます。ただし、新しいアプリの実態を未確認のまま掲載済みアプリの説明を流用しないでください。

1. 新しいアプリの実装、権限、SDK、通信先を確認します。
2. `ios.html` の日本語・英語の「アプリ別の取扱情報」に項目を追加します。
3. データの種類、目的、送信先、広告・分析・追跡、購入、アカウント、保存期間、削除方法を明記します。使わない機能も分かるようにします。
4. 新しい外部サービスがあれば、情報の取扱いとポリシーリンクを共通セクションにも追加します。
5. 実質的な変更がある場合は更新日を変更し、必要な利用者への通知・同意を準備します。
6. App Store ConnectのApp Privacy回答、プライバシーマニフェスト、権限の用途説明、アプリ内リンクと照合します。
7. 変更を公開し、ログイン不要でHTTP 200になることを確認してから、新しいアプリの公開・更新を行います。

共通ポリシーを作っても、App Storeのデータ収集申告がアプリ間で共通になるわけではありません。申告はアプリごとに行います。

## DaZen（2026-09-20 追加）

iOS版で初めて広告を表示するアプリです。これに伴い `ios.html` の共通方針を改めました。従来の「掲載するアプリでは広告目的で他社へ個人情報を提供しません」という言い切りは、広告を表示するアプリが加わった時点で成り立たないため、アプリごとに示す書き方へ変更しています。外部サービスにもGoogle（AdMob・User Messaging Platform）を追加しました。広告を表示しないアプリの取扱いは変わっていません。

Androidは `index.html` の「広告」が除外リスト方式のため、DaZenは記載を足さずとも「広告を表示するアプリ」に含まれます。配信元がGoogleであることと、UMPの同意フォーム・「広告設定を変更」の説明だけを追記しました。

DaZenが使うもの: AdMob（バナー）、User Messaging Platform（同意）、ATT/IDFA（iOSのみ、許可した場合）、StoreKit / Google Play Billing（買い切り `dazen_pro`）。位置情報・マイク・モーションセンサー・カレンダー・連絡先・写真は使いません。設定の「音の回転」は合成音のパンニングで、ヘッドトラッキングではありません。独自の分析・クラッシュ収集SDKはなく、当方のサーバーもありません。

## がっちゃんトレイン（2026-11-06 追加）

iOS版を初めて出すにあたり `ios.html` にアプリ別の項目を足しました。Androidは `index.html` の「広告」が除外リスト方式のため「広告を表示するアプリ」に含まれますが、年齢の確認と子ども向けの扱いを説明する段落を足しました。

がっちゃんトレインが使うもの: AdMob（リワード・全画面）、User Messaging Platform（同意）、ATT/IDFA（iOSのみ、13歳以上と答えて許可した場合）、StoreKit / Google Play Billing（買い切り `skin_animals`）、Appleのレビュー依頼（13歳以上のみ）、iOSの共有画面。最初の起動で年齢の区分をたずね、13歳未満かどうか・6歳以下かどうかだけを保存します。13歳未満は子ども向けの広告設定と保護者の確認、6歳以下は広告なし。位置情報・マイク・カメラ・連絡先・カレンダー・写真は使いません。折りたたみ端末のヒンジの状態は一時停止のために端末内でのみ使います。独自の分析・クラッシュ収集SDKはなく、当方のサーバーもありません。

## 色の匠（2026-11-11 追加）

iOS版を初めて出すにあたり `ios.html` にアプリ別の項目を足しました。Androidは `index.html` の「広告」が除外リスト方式のため「広告を表示するアプリ」に含まれ、本文は変えていません。

色の匠（Hue Squeeze）が使うもの: AdMob（バナーはホームと国旗あてクイズ、リワードはヒントが切れたとき）、User Messaging Platform（同意）、StoreKit / Google Play Billing（買い切り `huesqueeze_premium`）、Appleのレビュー依頼（星3つでクリアして次のレベルへ進むとき）、iOSの共有画面。iOSではATTを尋ねず、IDFAを使いません。保存するのはクリアの記録、ヒントの残り回数、購入済みかどうかの控え、レビュー依頼の条件に使う起動回数と日付だけで、すべて端末内です。位置情報・マイク・カメラ・モーションセンサー・連絡先・カレンダー・写真は使いません。独自の分析・クラッシュ収集SDKはなく、当方のサーバーもありません。

## 六曜暦iOS版の提出前に再確認する事項

- Open-Meteoの現行ポリシーは、IPアドレスおよび座標を含み得るログの保持（90日）を説明しています。開発者自身が受信しないことだけを理由に「データ収集なし」としないでください。外部サービスの実際の取扱いに照らし、位置情報・診断等の申告要否と目的を確認してください。
- 現在のコードはOpen-Meteoの公開APIを使用しています。無料APIの非商用条件と有料機能を含むアプリでの利用条件について、提供元の許諾・契約を確認してください。このページの公開によって利用許諾が得られるわけではありません。
- プライバシーポリシーとWeatherKitの法的帰属リンクは別のものです。両方をアプリ内に保持してください。
- このポリシーは実装と公開資料に基づく説明です。法域ごとの適法性や審査通過を保証するものではなく、必要に応じて専門家へ確認してください。
